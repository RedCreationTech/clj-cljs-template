## 私密业务的接入约定

需要保留操作时间、路径与状态，但不能把正文写入`sys_oper_log`的路由，在组级或具体HTTP方法加入 `:audit/body? false`。例如：

```clojure
["/private" {:auth? true :audit/body? false}
 ["/record" {:post {:perms "private:record:add" :handler handler}}]]
```

这只控制日志正文；认证和权限仍按路由正常执行。通用字段脱敏不能自动识别所有业务秘密；调用追踪可通过 `(trace/start! "service/key" {:sensitive-keys #{:customer-note}})` 增加业务字段，默认凭据保护不会因此关闭。

## 保留在业务项目中的内容

测评场景、评分规则、客户资料、报告学习、专家校准、OCR和AI/ASR适配不进入通用模板。原生捕获防护涉及产品截图策略及设备验收，未强制施加到整个模板。

私有加密、密钥轮换及备份恢复已在业务项目验证，但当前表、字段、目录、AAD和格式仍与该业务绑定。通用模块还需要表/行身份绑定、多实例维护锁、完整数据库对象覆盖和跨平台权限验证；本次不增加模板默认密钥运维负担。后续应作为明确选择的独立基础设施模块提供。

完整软件检查以`bb ci`、`bb release`、`bb mobile:compile`、`bb mobile:test`、`bb mobile:web`及真实界面回归为准。Docker任务的命令回归不等于本机Docker容器启动，Flutter Web也不等于Android/iOS真机验收。
